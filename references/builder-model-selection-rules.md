# Builder Model Selection Rules

只有当前 Codex 界面允许用户选择模型，并且建议能帮助控制成本或风险时才输出模型建议。无法选择时省略，不制造 B0/B1/B2/B3 档位。

## 能力建议

| 情况 | 建议 |
|---|---|
| XS/S、少量文件、低风险改动 | 标准代码模型即可 |
| M、多模块、登录、数据库、第三方 API | 使用强推理代码模型 |
| L、支付、权限、安全、迁移、大重构 | 使用最强可用代码模型 |

建议格式：

```text
如果当前界面支持模型选择，建议使用 <能力级别>，因为 <风险或复杂度>；若连续两次无法定位根因，再升级。
```

模型名称、价格和可用性会变化。不要假设用户拥有某个模型，也不要把模型选择写成完成项目的前置阻塞。
